# Advanced Excel Data Analytics & Reporting

## 📌 Project Overview
This repository contains a comprehensive Excel-based data analysis project focused on cleaning, transforming, and analyzing raw business data to generate meaningful insights and executive dashboards.

## 🛠️ Excel Tools & Techniques Used
* **Data Transformation:** Data cleaning, conditional formatting, text-to-columns.
* **Formulas & Functions:** Advanced formulas (`VLOOKUP`, `XLOOKUP`, `INDEX/MATCH`, `IF/IFS`, `SUMIFS`, `COUNTIFS`).
* **Data Summarization:** Dynamic Pivot Tables and Pivot Charts.
* **Business Intelligence:** Interactive dashboard construction with key KPI metrics and slicers.

## 📁 Repository Files
* `Тестирование Аналитик .xlsx` — Analytical assignment file with processed data and models.
* `Assignment.xlsx` — Source dataset and calculations.
